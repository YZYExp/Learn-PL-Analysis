# 扩展篇有限工程实验

Python 3.10+，仅用标准库，不调用外部服务。在工程根目录运行：

```bash
python3 examples/extension_checks.py
python3 -m unittest discover -s examples -p 'test_extension_checks.py' -v
```

三项自包含实验：

1. **退款恢复有限模型**：本地paid/pending/refunded，易失idle/waiting，远端效果次数至多探索到2。原子本地意图提交、稳定请求键、可选的远端原子去重+效果为明确假设。无去重得到8状态和“提交意图→送达→确认前崩溃→重送”的重复轨迹；有去重得到5状态，所有状态效果次数≤1。未包含并发、多个订单、乱序、键过期、磁盘损坏或真实网关实现；不据此声称真实服务端到端exactly-once。
2. **摘要失效闭包**：graph[node]列出其依赖。实现反向传播至所有消费者，支持环；它不重算摘要、不检查真实依赖记录是否完整。示意缓存键包含源码、语义、库模型、配置，但调用者仍需提供全部真实输入。
3. **有限CEGIS**：四个固定候选、18个显式输入（remaining∈{0,1,2}、requested∈{-1,0,1,2,3,4}），政策为`min(max(requested,0),remaining)`。从(0,0)开始，always-zero被(1,1)驳回，raw-request被(0,-1)驳回，clamp在该有限域通过。不是任意程序合成器，不以有限枚举证明无限整数域。

八项测试验证崩溃重复轨迹、有限模型中的幂等上界、菱形/循环依赖传播、非法依赖拒绝、缓存身份的模型与配置敏感性、弱测试不足与反例约束搜索。
