# 术语速查与易混概念

| 术语 | 本书含义与边界 |
|---|---|
| 程序语义 | 程序在给定语言模型下的行为含义 |
| 规格 / Specification | 希望程序满足的条件或可观察行为要求 |
| 具体状态 / Concrete state | 分析模型中的某个实际状态；不必等同物理机器全部状态 |
| 抽象状态 / Abstract state | 用较少信息表示一组具体状态或性质 |
| 静态分析 | 根据表示与模型推断程序性质，不依赖只运行某次输入 |
| 动态分析 | 从实际执行获得信息；结论受所覆盖执行限制 |
| 健全性 / Soundness | 相对于明确性质、模型和假设，分析没有遗漏其声称覆盖的行为；必须结合上下文理解 |
| 精度 / Precision | 分析区分实际行为与额外近似行为的能力，不能简单等同准确率 |
| 误报 / False positive | 报告的问题在相应真值标准下不成立 |
| 漏报 / False negative | 真值中的问题没有被报告；未知真值时不可直接统计 |
| May / Must | 分别回答可能成立、必然成立；合流规则取决于所求性质 |
| 路径敏感 | 保留路径条件或不同路径的状态差异 |
| 流敏感 | 区分程序点和执行顺序影响 |
| 上下文敏感 | 区分不同调用上下文；不等同理解业务上下文 |
| 对象敏感 | 常以接收者对象的抽象身份区分调用上下文的一类方法 |
| 别名 / Alias | 不同表达式可能指向同一存储位置或对象 |
| 污点 / Taint | 根据指定策略追踪某类数据来源与传播；不自动证明漏洞成立 |
| Sanitizer | 可指动态错误检测工具，也可指污点模型中的净化操作；两者必须区分 |
| 动态类型 | 类型检查或类型关联的部分工作在运行时进行 |
| 动态分派 | 在运行时选择被调用的实现 |
| JIT | 运行期间编译代码的机制 |
| 符号执行 | 使用符号状态与路径约束表示一类执行 |
| SMT | 在指定理论组合下判断逻辑公式可满足性；超时不是不可满足 |
| 模型检查 | 检查状态模型是否满足某种性质，结论依赖模型与探索边界 |
| Happens-before | 特定并发模型中定义的偏序关系，不是墙钟先后顺序 |
| ABI | 二进制组件交互约定，包括调用、数据布局等 |
| SIMT | GPU 将多个线程组织为共同调度执行的一种模型，具体细节取决于架构 |
| 反编译 | 从低层表示恢复较高层表示，通常不能唯一恢复原源码 |

术语的操作性定义以所在章的模型为准；不同论文可能使用不同精度与健全性约定，阅读时先核对作者定义。

## 扩展版术语

| 术语 | 含义与边界 |
|---|---|
| 证明助手 / Proof assistant | 用形式语言构造并检查证明的系统；证明结论仍取决于陈述、基础逻辑与模型对应 |
| 命题即类型 | 用类型表达命题、用该类型的项表达证明的一种联系；不能据此说所有日常类型检查都证明业务正确 |
| 依赖类型 | 类型可以依赖于项；例如用长度索引描述向量，实际保证仍取决于定义 |
| 证明内核 / Kernel | 检查核心证明项的可信组件；战术自动化与内核职责不同 |
| 可信计算基础 / TCB | 结论所依赖且未在同一论证中进一步验证的组件和假设 |
| 精化 / Refinement | 在规定观察与对应关系下，一种实现或模型满足另一种更抽象描述的允许行为 |
| 关系验证 / Relational verification | 同时关联两个或多个程序、运行或状态来表达并验证性质 |
| 分离合取 | 在指定资源模型中断言拥有可分离组合的资源；不等于变量名之间完全无别名 |
| 形状分析 / Shape analysis | 对堆中连接结构、共享与可达性作抽象推理 |
| 排名函数 / Ranking function | 把循环或递归映射到良基关系，证明每次推进都严格下降 |
| 摊还分析 / Amortized analysis | 对操作序列分摊总成本；不能直接推出每次操作的最坏延迟 |
| CEGAR | 检查抽象反例、据伪反例细化抽象的迭代框架；预算耗尽仍可能未知 |
| 非干扰 / Noninterference | 在明确输入和观察条件下，秘密变化不影响允许的低安全观察的一类关系性质 |
| 条件数 / Condition number | 问题本身对输入扰动的敏感程度，与某个具体算法的稳定性不同 |
| CEGIS | 生成候选、寻找反例、加入反例约束并再次生成的合成循环；有限语法和测试范围限制结论 |
| 摘要失效 | 已缓存结论的输入、语义模型或依赖改变后，旧结论不能继续直接复用 |
