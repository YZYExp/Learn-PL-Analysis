# 原始 Git 历史

`history.bundle` 保存本书此前完整的 17 个原始提交，末端为 `8998fe2d9c28b6193ce167053c4f7b78c79a85c5`，包含空 README 初始提交和后续规划、写作、审稿、验证步骤。

```sh
git clone archives/history.bundle original-book-history
```

本仓库通过 GitHub 提交接口按原顺序导入，导入各步骤的文件树与原提交逐一核对一致。接口生成的提交身份与时间不同，因此提交 SHA 不同；原始 SHA 和元数据以 bundle 为准。[import-map.json](import-map.json)记录对应关系。
