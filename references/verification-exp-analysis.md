## 数值例子实际核对

当前Python报告sys.float_info：radix=2，mant_dig=53，rounds=1，epsilon=2.220446049250313e-16。

实际运行结果：

```text
x = float(2**53)
(x + 1.0) + (-x) = 0.0
x + (1.0 + (-x)) = 1.0
x + 1.0 == x → True

z = float(2**54)
sqrt(z+1) - sqrt(z) = 0.0
1 / (sqrt(z+1) + sqrt(z)) = 3.725290298461914e-09
```

这些是本环境的具体结果，不构成所有编译器、库、硬件和输入域的全称证明。融合乘加例子为明确舍入规则下的推导，未宣称硬件实测。
